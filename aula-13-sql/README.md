# Aula 13 — SQL Lab / Oracle HR

Arquivo de respostas dos 20 exercícios do SQL Lab, organizado no formato de texto
utilizado pela opção **Exportar meu SQL** do HTML fornecido para a atividade.

As consultas foram preenchidas com base nas respostas trabalhadas na conversa.
O arquivo HTML guarda respostas e progresso no armazenamento local do navegador;
esses dados não vêm incorporados quando o HTML é enviado como arquivo.

Antes da entrega, recomenda-se abrir o SQL Lab no navegador, conferir as consultas
e executá-las no Oracle da aula. A verificação do próprio laboratório é orientativa
e não substitui a execução no Oracle.
